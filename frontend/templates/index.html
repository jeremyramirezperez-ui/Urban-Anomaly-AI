Funcionamiento

¿Qué hace SecurityAPPCR?

Analiza imágenes de una cámara web y aplica reglas configurables para detectar situaciones que requieren atención.

1

Detecta personas y objetos

YOLO identifica personas y objetos visibles durante el monitoreo.

2

Evalúa anomalías

Comprueba las reglas y condiciones configuradas en el sistema.

3

Genera alertas

Guarda la evidencia en SQL Server y envía correos automáticamente.
